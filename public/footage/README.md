# Footage Directory

Place your daily game video clips, GIFs, and screenshots in this folder.

### Supported formats:
- Video: `.mp4`, `.webm` (e.g. `day-1-movement.mp4`)
- Images/GIFs: `.gif`, `.png`, `.jpg`, `.webp` (e.g. `day-1-screenshot.png`)

### How to reference in your logs:
When adding an entry in `src/data/devlogs.ts` or through the web interface:
- Set url to: `footage/your-file-name.mp4`
